# 多人联机

项目现在支持 Luanti 的客户端联机、集成主机和独立服务器模式。单人游戏入口不变。

## 游戏内创建主机

1. 主菜单选择 **多人游戏 → 创建联机世界**。
2. 选择一个已经创建的世界，填写主机玩家名、账号密码和端口。
3. 默认端口是 **UDP 30000**；主机监听 `0.0.0.0`，因此可以接受局域网连接，也可以接受完成端口转发后的公网连接。
4. 朋友在 **多人游戏 → 加入服务器** 中填写主机 IP/域名、端口、玩家名和账号密码。

主机默认不向公共服务器列表广播，且禁止空密码账号。不要把重要网站或系统密码用于游戏账号。

## 局域网联机

主机在 Windows PowerShell 中运行 `ipconfig`，找到与朋友处于同一局域网的 IPv4 地址，例如 `192.168.1.20`。朋友连接：

```text
地址：192.168.1.20
端口：30000
```

首次运行时，Windows 防火墙需要允许 `runtime\luanti-5.17.0-win64\bin\luanti.exe` 的 **UDP 入站**连接。

## 非局域网 / 公网联机

公网联机不能只靠游戏代码自动完成，还需要网络侧允许入站连接：

1. 给主机电脑固定一个局域网地址，例如 `192.168.1.20`。
2. 在路由器中添加端口转发：**UDP 30000 → 192.168.1.20:30000**。
3. 在 Windows 防火墙中允许 Luanti 的 UDP 30000 入站。
4. 将主机的公网 IPv4 或域名发给朋友；朋友连接公网地址和 `30000` 端口。

如果宽带使用 CGNAT、无法配置路由器、或运营商屏蔽入站端口，普通端口转发不会生效。这时需要公网 VPS、支持入站的 IPv6，或合规的组网/隧道服务；项目不会自动绕过运营商网络限制。

## 独立服务器

不想一直打开客户端时，可以运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\server.ps1 -World "新的世界" -Port 30000
```

也可以双击根目录的 `Start-Server.cmd`。服务器日志写入 `evidence\server.log`；按 Ctrl+C 或关闭服务器窗口停止。

`server.ps1` 默认绑定 `0.0.0.0`、使用 UDP 30000、关闭公共列表广播并禁止空密码账号。只有在明确需要出现在公共服务器列表时才使用 `-Announce`。

## 注意事项

- 主机和客户端建议使用同一个项目版本；服务器端的世界存档和 Mod 版本应保持稳定。
- 公开服务器前请先备份 `runtime\luanti-5.17.0-win64\worlds`，并谨慎授予 `server`、`privs` 等管理权限。
- `aurum_axe` 等自定义 Mod 在服务器端生效；参与者最好使用同一发行包，以避免资源和版本差异。
- 服务器启动失败时先查看 `evidence\server.log`，重点检查端口占用、Windows 防火墙和路由器转发方向。
